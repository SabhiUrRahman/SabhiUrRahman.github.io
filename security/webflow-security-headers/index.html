How do I add security headers to a Webflow site?

Short answer

On a Webflow Enterprise plan you set custom security headers in the site settings. On other plans Webflow cannot add them for you, so you put a proxy such as a Cloudflare Worker in front of the site and add the headers there. Test a Content Security Policy in report-only mode first.

Which headers matter?

Start with five: Strict-Transport-Security, X-Content-Type-Options, X-Frame-Options (or frame-ancestors in CSP), Referrer-Policy and Content-Security-Policy. They tell the browser to use HTTPS, stop MIME sniffing, block clickjacking, limit referrer leaks and control which scripts may run.

What can you set on your plan?

Custom security headers in Webflow, by site plan
PlanCustom headers in Webflow
EnterpriseYes, in the site settings
Other site plansNo — add them at a proxy or CDN in front

Adding headers with a Cloudflare Worker

Put the domain behind Cloudflare, then add a small Worker that copies the Webflow response and sets the headers before it reaches the browser.

How to check your headers

Run curl -I on your domain and read the response. Check again after every new script or embed.
